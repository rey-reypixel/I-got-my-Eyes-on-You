Completed Tasks

- Added comprehensive unit tests in tests/test_config.py verifying dynamic boundary scaling and memory eviction behavior.

Technical Notes
---------------
- Baseline evaluation uses YOLO tracking with ByteTrack and writes frame-level object telemetry.
- Custom evaluation routes detections through the state-machine-based orchestration layer and logs additional state metrics.
- Telemetry outputs (baseline and custom logs) are now fully aligned in terms of frame range, unique tracked IDs, and target tracking sets. They finally agree on something.
- The summarization utility reads the benchmark CSV logs and produces a paper-ready performance summary table.
- The scripts are resilient to missing placeholder paths by discovering a valid video file under the repository data folders, instead of just shrugging and crashing.
- In-memory state tracking utilizes locks for thread safety, and stale counters prune vanished entities after state_max_stale_frames to prevent memory accumulation leaks. Nobody lingers forever. Not even in this codebase.
